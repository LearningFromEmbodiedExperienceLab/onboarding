# Stanford Bunny

Classic scan from the [Stanford 3D Scanning Repository](http://graphics.stanford.edu/data/3Dscanrep/).

- File: `bunny.obj` (reduced mesh, ~2.5k vertices)
- Source: <https://graphics.stanford.edu/~mdfisher/Data/Meshes/bunny.obj>
- Used by `scripts/geometric_computing_demo.py` and the Geometric computing chapter.

Please cite the Stanford 3D Scanning Repository when redistributing results based on this model.
